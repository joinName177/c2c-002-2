# c2c-002 · 情绪植物园

Vue 3 + TypeScript + Vite 纯前端情绪记录与虚拟植物花园。每日记录情绪会种下一株对应植物，连续记录让植物从种子、发芽、开花到结果；断签后保留枯萎标本，并提供生长时间轴和情绪生态年报。数据保存在浏览器 `localStorage`。

## 分层

- 核心层 `src/core`：情绪记录、连续天数、植物生长阶段、枯萎判断、生态年报、每日提醒到期判定
- 端口层 `src/ports`：花园快照仓储接口、提醒仓储接口、系统通知接口
- 适配器层 `src/adapters`：浏览器本地存储实现、`Notification` 浏览器通知实现
- 界面层 `src/ui`：Vue 页面与原生 CSS 视图

## 每日提醒

在「提醒」页可设置多个提醒，每个提醒包含时间与偏好的情绪类别：

- 到点且当天尚未记录时，通过浏览器通知提醒；点击通知直达「种植」页并预选该情绪
- 通知权限被拒绝、浏览器不支持或用户没点通知时，进入应用顶部出现一条当天有效的待办条，点击同样直达种植页并预选情绪
- 每个提醒每天只通知一次；当天完成记录后通知不再弹、待办条消失，第二天自动恢复
