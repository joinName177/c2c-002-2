# c2c-002 · 情绪植物园

Vue 3 + TypeScript + Vite 纯前端情绪记录与虚拟植物花园。每日记录情绪会种下一株对应植物，连续记录让植物从种子、发芽、开花到结果；断签后保留枯萎标本，并提供生长时间轴和情绪生态年报。数据保存在浏览器 `localStorage`。

## 每日提醒

在「提醒」页可设置多条每日提醒（提醒时间 + 偏好情绪）：

- 到点通过浏览器通知提醒，点击通知直接跳到种植页并预选好情绪；需要先授权通知权限。
- 通知权限被拒绝、浏览器不支持，或通知到点没点开时，花园顶部会出现一条**当天有效**的待办，点击同样跳到种植页并预选情绪。
- 当天完成任意一次记录后，所有待办立即消失、通知不再反复打扰；多条提醒与「今天是否已记录」由同一闸门统一裁决（见 `src/core/reminder-engine.ts`）。
- 待办只在当天有效，跨天自动作废；晚于提醒时间打开应用会补出当天待办，但不会补发系统通知。
- 提醒仅在应用打开期间通过页面内定时巡检生效（纯前端，无后台推送）。

## 分层

- 核心层 `src/core`：情绪记录、连续天数、植物生长阶段、枯萎判断、生态年报
- 端口层 `src/ports`：花园快照仓储接口
- 适配器层 `src/adapters`：浏览器本地存储实现
- 界面层 `src/ui`：Vue 页面与原生 CSS 视图
